EVERGREEN — PERSONAL LIFE APP

This is a small static web app. JavaScript interactions may not run inside a file preview; the app needs to be served from a website.

FREE PUBLISHING OPTION: GitHub Pages
1. Sign in to GitHub or create a free account.
2. Create a new public repository named evergreen-life (or another name).
3. Upload the three files in this folder: index.html, manifest.webmanifest, service-worker.js.
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for GitHub Pages to provide the website address.
7. Open that address in Safari on your iPhone and in your computer browser.
8. On iPhone Safari, tap Share → Add to Home Screen.

PRIVACY / DATA
Entries are saved in browser local storage. They stay separate on each device unless you export a JSON backup on one device and import it on the other. Do not enter sensitive information. Automatic cross-device syncing is not configured.

The app can be used without paid hosting, but publishing requires you to create and manage the GitHub repository yourself.
